## Overview

My Sweet Cafe is a modern, responsive cafe website featuring an AI-powered chatbot assistant. This React-based application showcases a beautiful cafe interface with menu sections, about page, and an interactive chatbot that helps customers with inquiries.

## Features

- 🚀 **Modern UI/UX Design**
  - Responsive layout for all devices
  - Smooth scrolling navigation
  - Attractive coffee menu display

- 🤖 **AI Chatbot Integration**
  - Interactive chatbot popup
  - Context-aware responses
  - Error handling and loading states
  - Customizable company information

- ☕ **Cafe Components**
  - Home hero section
  - Menu with coffee cards
  - About section with image
  - Contact information in footer

## Technologies Used

- **Frontend**
  - React.js
  - Tailwind CSS
  - React Icons
  - react-scroll for navigation

- **AI Chatbot**
  - Google Generative AI API
  - Custom chat components
  - Message history management
 

## Installation
 1. Clone the repository
  - git clone https://github.com/your-username/your-repo-name.git
  - cd your-repo-name

 2. Install dependencies
   - npm install
 3. Configure environment
   - Create a .env file in the project root:
   - VITE_API_URL=https://your-chatbot-api-endpoint
 4. Run the development server
   - npm run dev


## Customization
- To customize the chatbot responses and company information, modify the CompanyInfo constant in your project. 
- The chatbot greeting message and hidden company information can be adjusted in the initial chat history state.
